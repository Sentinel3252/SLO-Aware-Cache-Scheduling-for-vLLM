# Security reporting

CacheFlow is in early development. Security fixes target the current development
line; older releases do not have a separate maintenance commitment.

For a vulnerability, use the repository's **Security → Report a vulnerability**
option if private reporting is enabled. Otherwise, request a private contact from
the repository owner without publishing exploit details, prompts, credentials,
or private deployment information. There is no dedicated security mailbox or
guaranteed response time at present.

A useful report includes the affected CacheFlow and vLLM versions, configuration,
impact, and a minimal sanitized reproduction. Problems in upstream vLLM should
also follow upstream's security reporting process.

Ordinary scheduling, compatibility, and documentation bugs belong in GitHub Issues.
